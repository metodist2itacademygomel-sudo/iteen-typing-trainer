# Клавиатурный тренажёр ITeen Academy

Статическая версия для бесплатной публикации через **GitHub Pages**. Интерфейсные стили, шрифты и графические ресурсы взяты из предоставленной сборки; приложение переписано как лёгкий браузерный клиент. Сервер Node.js больше не нужен.

## Что реализовано

- Два независимых кабинета педагогов (создайте две учётные записи в Supabase Auth). Каждый педагог может создать одну собственную группу.
- Учитель управляет списком учеников своей группы; ученики не регистрируются и выбирают своё имя из списка.
- Педагог вставляет любой текст или загружает файл `.txt` (до 30 000 символов); новый текст становится текущим заданием группы, старые публикации остаются в истории.
- У ученика индивидуальная 10-минутная сессия с таймером, подсчётом скорости, ошибок и точности.
- Результаты сохраняются в Supabase; педагог видит историю группы и прогресс каждого ученика от занятия к занятию.
- Разделение данных обеспечивается Supabase Row Level Security (RLS), а не только скрытием интерфейса.

## 1. Создайте Supabase-проект

1. Создайте бесплатный проект на [supabase.com](https://supabase.com/).
2. Откройте **SQL Editor** и выполните весь файл `supabase/schema.sql`.
3. Откройте **Authentication → Users → Add user** и создайте две учётные записи педагогов. Можно задать email и пароль вручную. Не включайте публичную регистрацию.
4. Скопируйте **Project URL** и **anon / publishable key** из **Project Settings → API**.
5. Откройте `config.js` и замените значения `YOUR-PROJECT` и `YOUR_SUPABASE_ANON_KEY`.

`config.js` будет доступен посетителям сайта. Это нормально только для публичного anon/publishable key. **Никогда не вставляйте сюда `service_role` или secret key.**

## 2. Опубликуйте на GitHub Pages

1. Создайте **публичный** GitHub-репозиторий и загрузите в него содержимое этой папки (файл `index.html` должен лежать в корне репозитория). Не забудьте `config.js`.
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. В качестве ветки выберите `main`, папку — `/(root)`, затем нажмите **Save**.
5. Через несколько минут адрес сайта появится в Settings → Pages. После каждого нового push GitHub будет обновлять сайт автоматически.

## 3. Как работают педагоги и ученики

- Педагог нажимает **Для педагога**, входит по email и паролю, создаёт свою группу, добавляет детей и публикует текст.
- Второй педагог входит под своей учётной записью и создаёт вторую группу. У каждого аккаунта может быть только одна группа.
- Ребёнок открывает общий адрес сайта, выбирает свою группу, затем своё имя. Пароль ученику не нужен.
- Таймер начинается после нажатия **Начать 10 минут!**. По окончании или при досрочном завершении результат сохраняется.

## Важные замечания

- Бесплатный тариф Supabase имеет ограничения по объёму и не гарантирует SLA. Для небольших учебных групп обычно достаточно.
- Доступ к списку имён и текущему тексту открыт ученикам через ограниченные RPC-функции, поскольку иначе невозможно дать детям выбор из списка без регистрации. Данные учителей и статистика закрыты RLS и доступны только владельцу группы.
- Публичная форма отправки результата не может надёжно доказать, что ребёнок действительно печатал все 10 минут: браузер контролируется пользователем. Для учебного тренажёра это обычно приемлемо; серверная валидация ограничивает группу, ученика, занятие и длительность.
- Если ученик закроет вкладку до окончания и сохранения, незавершённая сессия не попадёт в статистику.
- Не добавляйте детям фамилии или другие избыточные персональные данные, если достаточно имени и первой буквы фамилии.

## Локальный просмотр

Для проверки можно открыть `index.html` через локальный веб-сервер (например, расширение Live Server в VS Code). Прямой запуск через `file://` может блокировать ES-модули браузера.

## Структура

- `index.html` — страница приложения.
- `assets/app.js` — логика интерфейса и Supabase.
- `assets/original-design.css` — сохранённая таблица стилей исходного дизайна.
- `assets/fonts.css`, `assets/fonts/` — оригинальные шрифты.
- `config.js` — публичные настройки Supabase.
- `supabase/schema.sql` — таблицы, RLS-политики и RPC-функции.
